# Práctica de Integración y Pruebas en Flutter (Semana 16)

Proyecto desarrollado para la evaluación de integración de componentes, gestión de servicios en Firebase, ejecución de pruebas automatizadas, análisis estático y control de calidad en Flutter.

## 📱 Descripción del Proyecto
Aplicación móvil construida en Flutter que integra autenticación de usuarios mediante Firebase Auth, sincronización y persistencia de datos con Cloud Firestore, navegación estructurada y manejo de notificaciones. La práctica contempla la verificación de flujos críticos, pruebas unitarias y de widgets, así como la gestión y resolución documentada de incidencias.
